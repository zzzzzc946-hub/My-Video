# MAX 视频技术错题集

本文件只记录可以复现、根因明确、修复已经验证的技术问题。它用于防止渲染、时间线、素材、字幕、字体、音频和输出错误重复发生。

## 与品牌校准的区别

- 用户明确确认的长期视觉、字幕、动画和音频规律写入 [`calibration-log.md`](calibration-log.md)。
- 稳定品牌规则写入 [`../references/max-video-profile.md`](../references/max-video-profile.md)。
- 只影响当前视频的一次性偏好留在该视频的需求单或装配表。
- 技术问题只有在根因和修复都得到验证后，才能写入本文件。

以下内容不进入技术错题集：

- “感觉不够高级”等尚未转化为可验证标准的审美反馈。
- 只出现一次且无法复现的问题推测。
- 尚未验证有效的修复方案。
- 根据参考视频猜测得到的 MAX 风格。

## 收录流程

1. 在制作需求单、装配表或交付检查表中保留问题现象和证据。
2. 复现问题，确认它不是一次性环境波动或误判。
3. 找到根因并完成修复。
4. 重新运行相关预览、静帧或完整渲染验证。
5. 只有验证通过后，按模板追加记录。
