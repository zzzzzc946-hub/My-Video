# 两机规则库接入指令

## 当前电脑：唯一决策中枢

本机 `CHEN BRAIN` 对应 `https://github.com/zzzzzc946-hub/CHEN-BRAIN.git` 的 `main`。开始视频前执行 `git pull --ff-only`，将 `git rev-parse HEAD` 写入本条任务卡。只有本机可裁决候选并修改正式 `00–07`；正式规则推送被拒绝时停止、拉取、重新检索，禁止强推。

收到另一台电脑候选后，检索相关03、06、Skill和open候选，裁决为不写入、合并证据、新建F1、修订或升级、本条经验或 REVIEW。更新正式规则与候选状态后一起提交推送。NAS 仅在用户明确要求时，从已确认提交单向镜像并记录 SHA。

## 另一台电脑：剪辑与候选节点

将 `https://github.com/zzzzzc946-hub/CHEN-BRAIN.git` clone 到本机 `CHEN BRAIN`。每条视频开始前执行 `git pull --ff-only` 并记录 SHA；结束后只从 `08｜规则候选收件箱/规则候选模板.md` 新建独立候选到 `open/`，提交并推送。

另一台电脑不得修改正式 `00–07`、`processed/`、NAS 规则正文、其他候选或同一视频的另一台工作草稿。离线时本地保留候选，联网后先拉取再推送；任何推送冲突不得强推，报告给当前电脑的决策中枢。
