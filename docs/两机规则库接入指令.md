# 两机规则库接入指令

## 共用启动协议

1. 在 CHEN-BRAIN 与 My-Video 工作副本执行 `git pull --ff-only`，只读取各自 `main`。
2. 读取 `current-release.yaml`，验证 active release 的 My-Video 提交已包含于本机 `HEAD`。
3. 记录并冻结 CHEN-BRAIN SHA、My-Video SHA、release ID 和最多 3 条候选；随后才创建本条 Goal（默认 40,000 Token）和成本台账。
4. 读取 `00` 路由与相关正式规则；候选只作补充证据，不能覆盖正式规则。

## 主电脑：decision-hub

主电脑是唯一正式裁决者。它从固定审阅批次读取候选与 blob SHA，完成检索、去重与冲突检查后，才可在正式治理 PR 中更新规则、processed、release 与 `current-release.yaml`。My-Video 的 Skill 或工作台变更必须先合入 `My-Video/main`，再由 release 激活。

## 次电脑：editor

次电脑长期剪辑但不写正式层。视频结束后创建本地候选草稿并使用治理命令干跑；服务器治理边界启用后以一个新的 candidate PR 提交。它不得改写已有候选、正式规则、processed、release、Skill、工作台或 NAS。

所有审片版本固定为 **1080P、30 fps**。NAS 只镜像已确认 active release，不能反向写入 Git。
