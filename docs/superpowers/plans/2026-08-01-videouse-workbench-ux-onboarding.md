# VideoUse 工作台 UX 与项目接入实施计划

目标：在不回归既有剪辑、安全、任务与导出能力的前提下，让用户明确选择 EDL/草稿分支，可靠绑定转写并连接当前本机实例，同时按已确认的 ChatCut × 剪映参考稿收口桌面工作台。

## 阶段 1：项目接入契约（TDD）

1. 为 EDL 候选、草稿启动模式、转写绑定结果、权威项目状态和本地反馈摘要补充共享类型。
2. RED：覆盖多 EDL 必须显式选择、继续草稿与隔离新草稿不混合、单源自动绑定与多源歧义、动态端口/实例运行时配置、反馈 JSON/Markdown。
3. GREEN：增加项目探测与显式打开流程；兼容旧草稿但不静默覆盖；无法裁决的转写留待 UI 绑定；所有写入仍固定在本次打开的 canonical 项目根。

## 阶段 2：实例与反馈闭环（TDD）

1. RED：动态 loopback 端口、Web 自动获得 API origin、旧实例/项目绑定可见且不被误认；反馈只记录元数据和操作类型，不包含转写正文或凭证。
2. GREEN：统一启动入口发布运行时配置；health/project 状态携带实例与绑定信息；项目级 feedback JSON/Markdown 随关键操作更新。

## 阶段 3：参考稿视觉还原

1. 重构为左侧贯穿高度、右侧上方素材/逐字稿 + 大播放器、下方完整时间线的三列布局，比例约 29% / 23% / 48%。
2. 使用中性炭黑、暖橙主操作、蓝色视频轨和绿色音频轨；收敛顶部操作层级。
3. 左栏显示自然语言剪辑摘要与折叠技术日志；中栏提供素材/资源库/逐字稿标签、搜索和真实媒体信息；播放器成为视觉焦点。
4. 时间线补齐工具栏、时间尺、播放头、轨道头和双层 A/V 视觉，同时保留修剪、分割、删除/恢复、调序、缩放、拖动和同步。
5. 所有分隔线保持 1px 视觉、约 8px 命中区、可拖动并持久化；图标使用开源图标库资源。

## 阶段 4：验证与交付

1. 逐阶段运行最小定向测试；最终运行完整 workbench 测试、lint/typecheck、workbench build、git diff --check。
2. 将真实 v002.2 项目复制到 `/tmp` 隔离目录，只执行一条桌面核心路径浏览器验收，不重新渲染视频。
3. 保存同 viewport 的参考图、实现图和并排图，修复全部 P0/P1/P2；项目根 `design-qa.md` 以 `final result: passed` 收口。
4. 独立自审变更和产物，确认源项目未写入后提交到 `codex/videouse-workbench`，不 push、不合并。
