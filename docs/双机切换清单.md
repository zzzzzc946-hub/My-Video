# MAX × VideoUse 双机切换清单

## 新电脑初始化

1. 安装 Git、Node.js、Codex 与 VideoUse；不复制 `node_modules`、缓存、草稿或 `.env`。
2. clone `My-Video` 与 `CHEN-BRAIN`，两者均跟踪 `main`；设置本机忽略的角色和 NAS 路径配置。
3. editor 使用独立 GitHub 协作者身份；decision-hub 使用唯一决策账号。两者都不得拥有分支保护 bypass。
4. 快进同步两个 `main`，校验 `current-release.yaml` 与 My-Video 兼容提交，再重新链接本机素材副本。

## 切换同一条视频

1. A 停止该视频的工作台写入与导出，保留本地可审阅版本；不覆盖原始 EDL、原片或历史交付。
2. A 确认任务卡记录的冻结 SHA、release ID 与候选 ID；未交付任务继续沿用该冻结快照。
3. B 同步两个 `main` 并验证 active release；若与冻结版本不一致，先在任务卡说明是否继续旧快照，不能静默替换。
4. B 从本地媒体路径重新授权并核对指纹、时长、方向和播放；重新生成本地代理。
5. 视频结束后，editor 只新增一个 candidate PR；decision-hub 再审阅与发布。

## 硬门槛

- 有未解决 `REVIEW`、未完成 active-release 校验或同一工作台草稿仍被另一台电脑写入时，停止切换。
- NAS 只做 active release 单向镜像与媒体备份，不能作为工作源或回写源。
- 审片与交付候选固定为 **1080P、30 fps**。
