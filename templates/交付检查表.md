- [ ] 画面与对应口播含义一致。

## 4. 字幕与屏幕文字

- [ ] 字幕没有漏句、复读或错位。

- [ ] 字幕和重点文字在安全区内。
- [ ] 文字没有溢出、裁切或被平台界面遮挡。
- [ ] 文字颜色、背景和描边具有足够可读性。
- [ ] 双语字幕的上下对应关系正确。

## 5. 视觉安全

- [ ] 人脸没有被字幕、卡片、素材或 Logo 遮挡。
- [ ] 字幕区没有被其他包装元素侵占。
- [ ] Logo 没有被裁切、拉伸、压扁或模糊。
- [ ] 关键素材没有超出画面或被错误裁切。
- [ ] 画中画窗口没有遮挡主要信息。
- [ ] 横竖屏或平台裁切后仍保留关键信息。
- [ ] 画面边缘没有意外黑边或透明缝隙。

## 6. 动画与转场

- [ ] 开场动画的前、中、后状态均已检查。
- [ ] 复杂转场的前、中、后状态均已检查。
- [ ] 动画没有跳帧、闪烁、瞬移或结束状态错误。
- [ ] 入场、停留和退场时长与阅读需求匹配。
- [ ] 没有全片持续使用同一种强动效。
- [ ] 转场服务于内容结构，没有遮盖口播信息。
