# MAX 剪辑工作流与工具路由

## 核心原则

MAX 粗剪流程是**工具无关**的；ChatCut、VideoUse 和未来新增的工具只是执行层。不能因为某个工具已安装，就自动启动它的本地流程。

## 每条视频的固定流程

1. 读取 MAX 规则、任务卡和必要案例，确认人物边界、账号目标与本条要求。
2. 选择本条的执行工具，并写入项目记录：默认 VideoUse；用户明确需要可见时间线或 ChatCut 云端 Agent 时才选 ChatCut。
3. 导入素材、取得可核对的转写和时间码；由所选工具完成，不调用未选择的工具。
4. Codex 依据 MAX 规则完成内容判断：钩子、结论、论证、例子、可删段、调序风险与表达精修点。
5. 内部保存可审阅粗剪方案（结构、时间码、删改理由、预计时长与风险），按用户2026-10-17长期授权直接执行、自审并交付最终成片，无须常规策略确认。
6. 在所选工具中完成剪切、修剪、移动、删除、字幕或预览；保留版本和可回退决策。
7. 检查逻辑、语义保真、音画同步、切口、开头、结尾与导出可播放性。
8. 留存过程文档和用户反馈；每条视频完成时统计可重建草稿，累计达到 10GB 才提醒人工清理。

## 工具选择

| 情况 | 默认选择 |
| --- | --- |
| 日常 MAX 口播粗剪、低成本本地执行 | VideoUse |
| 用户明确需要可见时间线、ChatCut 云端 Agent 或在 ChatCut 内协作 | ChatCut |
| 新工具更适合当前视频 | 新工具，但仍遵循上述八步流程 |

一条视频只启动当前选定工具的实际执行流程。切换工具要记录原因；已有决策和文档不因切换而丢失。
