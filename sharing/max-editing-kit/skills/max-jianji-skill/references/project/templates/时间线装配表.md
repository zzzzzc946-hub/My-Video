## 状态定义

- `待规划`：只有时间码和口播，尚未确定画面方案。
- `待素材`：方案明确，但必要素材未齐。
- `待制作`：方案和素材齐全，可以进入 Remotion。
- `制作中`：正在实现。
- `待检查`：实现完成，尚未通过 Studio 和静帧检查。
- `已通过`：片段已完成检查。
- `返工`：验证或用户反馈要求修改。

## 画面形式参考

按内容目的选择，不把参考形式自动当作 MAX 长期风格：

- 真人主画面
- 真人画中画＋全屏素材
- 全屏图片或视频
- 标题卡或章节卡
- 信息卡、数据卡或对比卡
- 图表或流程图
- 屏幕演示与局部聚焦
- 纯字幕强调
- 有意留白，不增加包装

## 片段设计检查

- [ ] 每个包装片段都有起始时间码和结束时间码。
- [ ] 每个片段都有明确的内容目的，不只是“加个动效”。
- [ ] 口播、字幕和粗剪版本一致。
- [ ] 素材文件名、来源和使用范围已经记录。
- [ ] 动效包含入场、停留和退场或结束状态。
- [ ] 音效与音乐处理已经说明，未连续堆叠重音效。
- [ ] 人脸、字幕、Logo 和关键信息没有区域冲突。
- [ ] 不需要包装的片段已经明确标记。
- [ ] 代表性关键帧已经选定。
